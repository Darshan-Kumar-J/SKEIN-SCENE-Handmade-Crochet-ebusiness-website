## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/skein-scene-crochet-store.git
```

### 2. Navigate to the project directory

```bash
cd skein-scene-crochet-store
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env.local` file in the root directory.

Example:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=

NEXT_PUBLIC_RAZORPAY_KEY_ID=
RAZORPAY_KEY_SECRET=

SUPABASE_SERVICE_ROLE_KEY=

NEXT_PUBLIC_SITE_URL=
```

Keep secret keys server-side. Never expose payment secrets or Supabase service-role credentials in client-side code.

### 5. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
